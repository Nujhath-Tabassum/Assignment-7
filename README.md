# Project Name: বাজার দর (BazarDor)

# Project Description:
BazarDor is a web application that helps people in Bangladesh check the prices of everyday market products. Users can browse different product categories and see how prices change over time. The goal is to make it easier for people to stay updated on market prices.


# Technologies Used:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB
- REST API


# Features

- Check the latest available prices of everyday products.
- Compare today's prices with previous prices to see how they have changed.
- Browse products by category to find what you need.
- Sign in or create an account using email, Google, or GitHub.
- Use the website easily on mobile phones, tablets, and computers.
